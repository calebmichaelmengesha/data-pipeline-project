#SEC Financial Data Pipeline
## Project Overview

An end-to-end data engineering project that extracts, transforms, and analyzes financial statement data from publicly traded companies using the SEC EDGAR API.

## Project Goals

1. Extract quarterly and annual financial dat
2. Clean and standardize financial information
3. Store processed performance and trends.
4. Automate the pipeline using cloud technologies.

## Technologies

- Python
- SEC EDGAR API
- Pandas
- SQL
- Git & Github
- Azure or AWS (planned)

## Project Status

In development - initial environment setup.
